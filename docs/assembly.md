# 🛠️ iRobapp-mini ハードウェア組み立て手順書

本ドキュメントは、3Dプリントした筐体パーツ（001〜004）と電子部品、サーボモーターを組み合わせて、iRobapp-miniを完成させるための公式手順書です。

## 📥 準備するもの

### 1. 3Dプリントパーツ
*   [ ] `001_Head_Face_Connector`（頭部マウント）
*   [ ] `002_Neck_Joint_Mount`（首ジョイントマウント）
*   [ ] `003_Body_Base_Case`（本体ボトムケース/土台）
*   [ ] `004_Bottom_Lid_Battery_Holder`（フラットボトム蓋）

### 2. 主要電子・メカ部品
*   [ ] 丸型液晶ディスプレイ（WAVESHARE 1.28inch LCD Module (19192)） × 1
*   [ ] サーボモーター（SG90） × 2（首振り用、尻尾用）
*   [ ] サーボ付属一文字プラスチックホーン × 2、固定用ミニビス一式
*   [ ] メインマイコン（XIAO ESP32-S3） × 1
*   [ ] オーディオアンプ基板（MAX98357A） × 1
*   [ ] 小型スピーカー × 1

*   [ ] パネルマウント型ヒューズホルダー × 1

## 🛠️ 組み立て 4ステップ

### 【ステップ1】頭部（001）と首（002）の合体
1.  **液晶の配線エスケープ**
    *   丸型液晶(WAVESHARE 1.28inch LCD Module (19192))の背面から出ている配線コードの束を、001の中央にある**直径22mmの大きな丸穴**にストンと通します。
2.  **液晶のフロントはめ込み**
    *   配線を引っ張りながら、液晶本体を001前面の直径38mmのポケットへ優しく押し込み、フラットにハメ込みます。
3.  **首（002）とのドッキング**
    *   90度起こして液晶を正面に向けた001の背面に対して、首パーツ（002）の「前面（縦の壁）」を後ろからハグするようにぴったり重ね合わせます。
    *   002の前面に開いている3つの水平穴のうち、上下2箇所の固定ネジ穴を使って、M2ネジで001と002をがっちり締め付け固定します。
4.  **配線の引き込み**
    *   001の底から出たコードを、002の天面のR11丸穴からコの字の内側（空洞）へと引き込みます。首が回転したときのために、ここで配線に数ミリの「たるみ（余裕）」を持たせておきます。

### 【ステップ2】土台（003）への駆動源（サーボ）の組み込み
1.  **首振り用（左右パン）サーボの固定**
    *   土台（003）の最天面にある長方形スリットに、サーボモーター（SG90）を上から差し込みます。
    *   サーボの黒い本体は内側に隠れ、ギザギザの「白い回転軸」が真上を向いて飛び出します。これを天面の左右からM2ネジ2本でしっかり固定します。
2.  **尻尾フリフリ用サーボの固定**
    *   土台（003）の背面最上部にある専用窓に、2つ目のサーボ（SG90）を横向きに寝かせて埋め込みます。
    *   回転軸が「真後ろ（外側）」に向かって飛び出す向きにはめ込み、左右からM2ネジ2本で樹脂壁に固定します。

### 【ステップ3】頭部ユニットと土台（003）の連結
1.  **首の底面へのホーン装着**
    *   ステップ1で組み立てた頭部ユニット（001+002）を用意します。
    *   002の底面裏側にある専用溝（`horn_pocket`）に、サーボ付属の一文字型プラスチックホーン（白い羽）をパチンとはめ込み、両脇の2穴をミニビスでネジ留めします。
2.  **配線の土台へのエスケープ**
    *   002のコの字の内側を通っている液晶からの配線コードを、003の天面の右下に新設した**直径10.0mmの配線専用大穴**から、土台のドーム内部（インナーポケット）へとストンと引き込みます。
3.  **回転軸のドッキングとネジ締め**
    *   002の底面に付けたホーンの穴を、003の天面から飛び出している首振りサーボの回転軸（ギザギザ）に上からグッと押し込んで噛み合わせます。
    *   コの字の正面開口部から細いプラスドライバーを水平に差し込み、002底面中央の穴を通して、サーボ付属の中心ネジを垂直に締め付けて固定します。

### 【ステップ4】内部配線とボトム蓋（004）の閉鎖
1.  **電子部品の格納**
    *   『統合ピンアサイン・配線表』の通りにすべてのハンダ付け・配線を完了させます。
    *   XIAOマイコンを、003の左後ろ側にある「USB-Cアクセス窓」の真裏に合わせ、接着またはテープで固定します。
    *   アンプ、スピーカー、スイッチ、ヒューズホルダーをそれぞれの指定位置へカチッとはめ込み、最後にLiPoバッテリーをドーム内の空きスペースへ直置きで収めます。
2.  **フラットボトム蓋（004）の閉鎖**
    *   すべての配線がサーボのギザギザやスイッチに噛み込んでいないか確認します。
    *   ただの丸い円盤である底蓋（004）を、003の底の大開口部（直径64mm）へ下からまっすぐ押し込みます。3Dプリント特有の摩擦と締め付けにより、「カチッ」と小気味よくはまり込んでロックされます。
    *   取り外したい時は、004の真ん中に生えている2本の出っ張り（つまみ）を指でピンコとつまんで、真下に真っ直ぐ引き抜くだけで、いつでも簡単にスポンと外せます。
