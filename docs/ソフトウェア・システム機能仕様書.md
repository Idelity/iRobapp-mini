# 📱 iRobapp-mini ソフトウェア・システム機能仕様書

本ドキュメントは、iPhone（コントローラー）とiRobapp-mini（エッジロボット）間の協調動作、通信プロトコル、および各機能の実装要件を定義するマスター仕様書である。

---

## ⚙️ 1. システムアーキテクチャ & 通信
*   **筐体/デバイス**: 
    *   **コントローラー**: iPhone (iOSアプリ)
    *   **ロボット**: XIAO ESP32-S3
*   **通信方法**: Bluetooth Low Energy (BLE) 通信
    *   iPhoneをマスター（セントラル）、ESP32-S3をスレーブ（ペリフェラル）として構成。
    *   音声データは、BLEの最大ペイロードおよびスループットを考慮し、パケットに分割してストリーミング転送を行う。

---

## 🧠 2. 統合機能仕様

### 🎙️ A. おしゃべり機能（音声パイプライン）
ハンダ付けを回避したシンプルなハードウェア構成で高音質な対話を実現するため、以下のパイプラインで音声を処理する。

1.  **音声認識 (STT)**: iPhone側でユーザーの発話を音声認識し、テキスト化。
2.  **思考 (AI)**: テキストを後述のAIエンジン（CloudまたはLocal）に投入し、返答テキストを生成。
3.  **音声合成 (TTS)**: 返答テキストをiPhone側で音声波形データ（音声ファイル）に合成。
4.  **データ圧縮**: iPhone側で音声を圧縮（例：OpusやADPCM、または生PCMのダウンサンプリング等、ESP32の解凍負荷が低い軽量フォーマットを選定）。
5.  **BLE転送**: 圧縮された音声ファイルをパケット分割し、BLE経由でESP32-S3へ高速転送。
6.  **再生**: ESP32-S3側でデータを受信・解凍し、I2S経由でMAX98357Aアンプを叩き、スピーカーからロボットの声として再生。

### 🤖 B. AI連携機能（マルチLLM/SLMエンジン）
ユーザーの利用環境やコストの好みに合わせて、iOSアプリの設定画面から2つのモードを切り替え可能とする。

*   **有料版 (Cloud LLM)**: 
    *   **エンジン**: OpenAI ChatGPT API
    *   **要件**: アプリの設定画面で、ユーザー自身が契約した「OpenAI APIキー」を入力して通信を行う。
*   **無料版 (Local SLM)**: 
    *   **エンジン**: Phi-3 (Microsoft)
    *   **要件**: iPhoneのローカルリソース（CoreML / ONNX Runtime等）を利用し、事前にアプリ内にダウンロードしたモデルを用いて完全オフラインで推論を実行。

### ⚙️ C. 首振り機能（パンサーボ制御）
1.  **トリガー動作**: ユーザーがiPhoneに話しかけたタイミングで、ロボットはiPhone（ユーザー）がいる方向を向くように体を回転させる。
2.  **自律動作（ランダム探索）**: アプリの動作モードに応じて、タイマーおよび乱数（ランダム値）に基づいた時間間隔で、不定期に首をきょろきょろと左右に回転させ、生命感を演出する。

### ⚙️ D. 尻尾振り機能（テールサーボ制御）
1.  **トリガー動作**: ユーザーがiPhoneに話しかけた（インタラクションが発生した）タイミングで、尻尾をキュキュッと「2回」小気味よく振る。
2.  **自律動作（ゴキゲン演出）**: 首振り機能と同様に、モードに応じた乱数値ベースの間隔で、自律的に尻尾をフリフリと動かす。

### 📺 E. 瞬き・視線連動機能（GC9A01グラフィック制御）
LovyanGFXを用い、丸型液晶の中に「目（瞳）」をリアルタイム描画する。

1.  **瞬き（まばたき）**: 3パターンの時間間隔を乱数で切り替えながら、自然な瞬きを繰り返す。
2.  **スリーブモード**: 長時間ユーザーからの操作や発話がない場合、スリープ状態に移行して瞳を完全に閉じ、消費電力を抑える。
3.  **視線連動（上下3パターン）**: iPhone（コントローラー）とロボットの物理的な位置関係、またはアプリ上の操作に基づき、瞳の上下角度を3パターンから自動決定する。
    *   *iPhoneが上にある場合*: 黒目を「上」に向ける（見上げる）。
    *   *iPhoneが水平な場合*: 黒目を「真ん中」にする（正面）。
    *   *iPhoneが下にある場合*: 黒目を「下」に向ける（見下ろす）。
