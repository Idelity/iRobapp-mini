# 📱 iRobapp-mini ソフトウェア・システム機能仕様書 

本ドキュメントは、iPhone（コントローラー）とiRobapp-mini（エッジロボット）間の協調動作、通信プロトコル、および各機能の実装要件を定義するマスター仕様書である。

---

## ⚙️ 1. システムアーキテクチャ & 通信
*   **筐体/デバイス**: 
    *   **コントローラー**: iPhone (iOSアプリ)
    *   **ロボット**: XIAO ESP32-S3
*   **通信方法**: Bluetooth Low Energy (BLE) 通信
    *   iPhoneをマスター（セントラル）、ESP32-S3をスレーブ（ペリフェラル）として構成。
    *   音声データは、遅延を最小化するためパケット単位での「リアルタイム音声ストリーミング方式」を採用する。

---

## 🧠 2. 統合機能仕様

### 🎙️ A. おしゃべり機能（音声ストリーミング）
ハンダ付けを全廃したハードウェア構成で低遅延な対話を実現するため、以下のパイプラインで音声を処理する。

1.  **音声認識 (STT)**: iPhone側でユーザーの発話を音声認識し、テキスト化。
2.  **思考 (AI)**: テキストを後述のAIエンジン（CloudまたはLocal）に投入し、返答テキストを生成。
3.  **音声合成 (TTS)**: 返答テキストをiPhone側でリアルタイムに音声データに合成。
4.  **ストリーミング転送**: iPhone側で軽量圧縮した音声を細切れのパケットデータとして、BLE経由で順次ESP32-S3へストリーミング送信。
5.  **リアルタイム再生**: ESP32-S3は受信したバッファを順次解凍し、I2S経由でMAX98357Aアンプを叩き、スピーカーから即座に再生。

### 🤖 B. AI連携機能（マルチLLM/SLMエンジン）
ユーザーの利用環境やコストの好みに合わせて、iOSアプリの設定画面から2つのモードを切り替え可能とする。

*   **有料版 (Cloud LLM)**: 
    *   **エンジン**: OpenAI ChatGPT API
    *   **要件**: アプリの設定画面で、ユーザー自身が契約した「OpenAI APIキー」を入力して通信を行う。
*   **無料版 (Local SLM)**: 
    *   **エンジン**: Gemma 2B (Google) ※デバイスローカル動作
    *   **要件**: iPhoneのオンデバイスAIランタイムを利用し、完全オフラインで高速な推論を実行する。
    *   *備考*: Microsoft Phi-3の対応は将来的な拡張予定（バックログ）とする。

### ⚙️ C. 首振り機能（パンサーボ制御）
1.  **トリガー動作**: ユーザーがiPhoneに話しかけたタイミングで、ロボットはiPhone（ユーザー）がいる方向を向くように体を回転させる。
2.  **自律動作（ランダム探索）**: アプリの動作モードに応じて、タイマーおよび乱数（ランダム値）に基づいた時間間隔で、不定期に首をきょろきょろと左右に回転させ、生命感を演出する。

### ⚙️ D. 尻尾振り機能（テールサーボ制御）
1.  **トリガー動作**: ユーザーがiPhoneに話しかけたタイミングで、尻尾をキュキュッと「2回」小気味よく振る。
2.  **自律動作（ゴキゲン演出）**: 首振り機能と同様に、モードに応じた乱数値ベースの間隔で、自律的に尻尾をフリフリと動かす。

### 📺 E. 瞬き・視線リアルタイム演算機能（液晶グラフィック制御）
LovyanGFXの強力な幾何学図形描画機能を利用し、WAVESHARE 1.28inch LCD Module (19192)［制御IC: GC9A01］にデジタルな瞳をリアルタイム合成する。

1.  **瞬き（まばたき）**: 3パターンの時間間隔を乱数で切り替えながら、自然な瞬きを繰り返す。
2.  **スリープモード**: 長時間ユーザーからの操作や発話がない場合、スリープ状態に移行して瞳を完全に閉じ、消費電力を抑える。
3.  **視線リアルタイム追従（将来拡張用）**: 
    *   iPhone側から送られてくる角度や各種座標数値データをESP32-S3がリアルタイムに受信。
    *   LovyanGFXの関数（`fillCircle` 等）を使い、**黒目の円の座標（Y軸）をリアルタイム計算でスムーズに滑らかに動かす**表現を実装する。
    *   *備考*: iPhoneとロボットの物理的な位置関係による完全自動の視線連動は将来のアップデート予定とする。
