# iRobapp-mini 画像・図面アセット管理

このフォルダには、`iRobapp-mini` の設計、回路、ドキュメントで使用する画像やデザインの元データを格納しています。

---

## 🔌 回路結線図の更新ルール 🎵

回路図（ピンアサインや配線）に変更があった場合は、以下の手順でデータを更新してください！
画像ファイル名（`.png`）とフリーボードのファイル名（`.freeform`）は、常に同じ名称（`circuit-diagram`）で統一して管理しています。

### 🔄 更新の 3 ステップ

1. **Mac のフリーボードで修正する**
   * 同フォルダにある元データ `circuit-diagram.freeform` を Mac で開き、ピンアサインや配線をパパッと修正します。
2. **画像（PNG）として書き出す**
   * 修正が終わったら、フリーボードから「PDFとして書き出し」→「PNG形式（ファイル名：`circuit-diagram.png`）」として Mac に保存します。
3. **GitHub へ上書きアップロード！**
   * GitHub のこのフォルダ（`docs/images/`）を開き、新しく作った `circuit-diagram.png` と `circuit-diagram.freeform` の両方を**同じファイル名のままドラッグ＆ドロップ**して上書きコミットします。

> 💡 **ここがポイント！**
> ファイル名が同じであれば、ドキュメント（`ピンアサイン・配線表.md`）側のリンクを書き直さなくても、自動的に最新のきれいな回路図にパッと切り替わります！
