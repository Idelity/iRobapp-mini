# 🤖 iRobapp-mini 卓上マスコット：3大コア部品の設計解説

本プロジェクト（iRobapp-mini）のハードウェア骨格は、FreeCADスクリプトから自動生成される**「3つの独立したコンポーネント」**が密接に連携することで成り立っています。それぞれの役割と設計思想は以下の通りです。

## 1. 001_Head_Face_Connector（頭部フェイスマウント）
* **【役割】**：丸型液晶（GC9A01）をガタつきなく前面にホールドし、視線アニメーションを表現する「顔」の筐体です。
* **【形状的特徴】**：直径44mmの非常にコンパクトなコップ型の円柱ベース。
* **【設計のこだわり】**：
  * 底面に幅8mm×長さ36mmの**フラットな「耳（拡張ブロック）」を一体化**させ、コンパクトな丸型ヘッドのデザインを維持したまま、首サーボと繋ぐネジ穴ピッチ（27.5mm）を綺麗に確保しています。
  * 中央に16mmの角型貫通穴を配置し、液晶背面からのFPCケーブルやジャンパ線をそのまま首の下へと美しく逃がせる設計（配線エスケープ構造）になっています。

## 2. 002_Neck_Joint_Mount（首ジョイントマウント）
* **【役割】**：頭部（001）と底面ベース（003）を物理的に繋ぎ、マスコットに「見上げる・うつむく・かしげる」といった愛らしい感情表現（チルト/ピッチ運動）を与える中間関節パーツです。
* **【設計のこだわり】**：
  * 001の底面に設けられた「M2ネジ穴ピッチ27.5mm」と完全に寸法が一致するようスクリプトで同期されています。
  * SG90サーボモーターの回転軸（スプライン）と直接、あるいはサーボホーンを介して強固にビス留めできるホーン受けの凹みや嵌合（かんごう）形状が計算されています。
  * 頭部からの配線が首の回転によって引っ張られたり断線したりしないよう、コードの通り道となるスリットや中空構造が取り入れられています。

## 3. 003_Body_Base_Case（本体ボトムケース）
* **【役割】**：首を駆動させるSG90サーボモーターそのものを内包し、さらにメインマイコンである「XIAO ESP32-S3」やバッテリー等の電子部品をすべて収納する、マスコットの「体」であり「土台」となるパーツです。
* **【設計のこだわり】**：
  * 卓上でマスコットが頭を動かした時に、慣性で倒れないように低重心な設計（安定した末広がり、またはドーム形状）になっています。
  * XIAOマイコンのUSB-Cポートが外側から干渉せずにカチッと挿せるよう、正確な寸法で外抜き用の窓（エンクロージャー穴）がブーリアン演算でくり抜かれています。
  * 内部で各基板を固定するためのボス（ネジ留め突起）や、スナップフィット構造がスクリプト内で定義されています。

---

### 💡 設計思想の評価（パラメトリック・モジュール化）
FreeCAD上でパーツごとにスクリプトを分離したことで、**「頭（液晶表示・配線窓） ↔ 首（サーボ結合・M2ピッチ27.5mm） ↔ 体（サーボ格納・マイコン固定）」**という一連の物理的・機能的リンクが綺麗にカプセル化されています。
これにより、「液晶のサイズを変えたい時は001だけ」「サーボを別のものに変えたい時は002と003だけ」というように、他の部品に影響を与えずパラメトリックに独立してカスタマイズできる点が非常に優れた設計思想です。
