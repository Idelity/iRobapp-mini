# 💻 Macローカル開発環境構築 ＆ GitHubフォルダ同期手順書

本ドキュメントは、Macのローカル環境（書類フォルダ）における『iRobapp-mini』のディレクトリ作成、Xcodeプロジェクトのクリーンな配置、およびGitHubリポジトリへ正しい構造でプッシュ（同期）するまでの手順を定義した公式開発ガイドです。

---

## 📂 最終的に目指すフォルダ構造（ローカル・クラウド共通）

Gitの標準的なベストプラクティスに基づき、リポジトリのルート（一番上の階層）に `.gitignore` を配置し、そこから `iOSApp` や `firmware` を一括監視・管理するプロ仕様の構成を目指します。

```text
iRobapp-mini/ (リポジトリのルート)
├── 📄 .gitignore                    # Xcodeのビルドゴミや個人設定を一網打尽にする除外設定
├── 📁 docs/                         # 各種仕様書・手順書
│   ├── 📄 software_spec.md          # ソフトウェア機能仕様書
│   └── 📄 assembly.md               # ハードウェア組み立て手順書
├── 📁 firmware/                    # ロボット（ESP32-S3）側のプログラム
│   └── 📁 main/
│       └── 📄 main.ino              # 最新環境対応ファームウェア
└── 📁 iOSApp/                       # iPhoneアプリ（Xcode）を収める公式フォルダ
    └── 📁 iRobappMiniController/    # ① 外側のフォルダ：プロジェクト全体を包む箱
        ├── 📄 iRobappMiniController.xcodeproj # ② Xcodeを起動するためのアイコンファイル
        └── 📁 iRobappMiniController/ # ③ 内側のフォルダ：Swiftソースコードが詰まった本丸
            ├── 📄 BLEManager.swift
            ├── 📄 VoicePipelineManager.swift
            └── 📄 ContentView.swift
```

## 🛠️ 開発環境構築 4つのステップ

### 【ステップ1】Macの『書類』へ作業ディレクトリの作成
まずはMacのターミナル（またはFinder）を使い、すべての開発のベースとなる大元フォルダを作成します。

```bash
# 1. Macの「書類 (Documents)」フォルダへ移動
cd ~/Documents/

# 2. プロジェクトのルートとなる「iRobapp-mini」フォルダを新規作成
mkdir -p iRobapp-mini

# 3. 作成したフォルダの中へ移動
cd iRobapp-mini
```

### 【ステップ2】Xcodeでの新規プロジェクト立ち上げ
1. Xcodeを起動し、**［Create new Xcode project］** をクリックします。
2. プラットフォームで **［iOS］** を選び、**［App］** を選択して ［Next］ を押します。
3. プロジェクト情報を以下のように入力します。
   * **Product Name**: `iRobappMiniController`
   * **Interface**: **［SwiftUI］** (必須)
   * **Language**: **［Swift］** (必須)
4. 保存先（開いたダイアログ）として、先ほど作成した **`~/Documents/iRobapp-mini/`** の中を選択し、［Create］ ボタンを押してプロジェクトを生成します。
   * ※この時点で、外箱フォルダの中に `.xcodeproj` と、コードの詰まった同名の内箱フォルダが並ぶ、正常なXcode標準構造が自動生成されます。

### 【ステップ3】公式の「iOSApp」フォルダへの引っ越しと構造整理
Xcodeがデフォルトのままで作った外箱フォルダ（`iRobappMiniController`）を、GitHubの狙い通りのフォルダ構成（`iOSApp/iRobappMiniController/`）にするため、ターミナル上でフォルダを1階層奥へ引っ越しさせます。

```bash
# 1. ターミナルでリポジトリのルートにいることを確認
cd ~/Documents/iRobapp-mini/

# 2. 成果物をまとめるための「iOSApp」フォルダを新規作成
mkdir -p iOSApp

# 3. Xcodeのプロジェクト（外箱ごと）を「iOSApp」フォルダの中へ綺麗に移動
mv iRobappMiniController iOSApp/
```
> ⚠️ **【開発時の注意点】**
> このフォルダ移動を行った後も、MacのFinder等から `iOSApp/iRobappMiniController/iRobappMiniController.xcodeproj`（白いアイコン）をダブルクリックして開けば、これまで通り全く問題なくXcodeで開発・コンパイルを続けることができます。

### 【ステップ4】`.gitignore` の設定とGitHubへの完全同期
Xcodeがビルドのたびに自動生成する膨大な「一時キャッシュ（DerivedData）」や「個人用UserData」がGitHubへ誤ってプッシュされ、リポジトリがゴミで肥大化したり個人情報が露出したりするのを防ぐため、ルートの `.gitignore` を編集して一括同期します。

1. `iRobapp-mini/` 直下（ルート）にある `.gitignore` ファイルをテキストエディタで開き、以下のXcode除外設定を**一番最後の行に追記**して保存します。

```text
# =========================================================================
# Xcode (iOSApp) 関連の除外設定
# =========================================================================
build/
DerivedData/
*.pbxuser
!default.pbxuser
*.mode1v3
!default.mode1v3
*.mode2v3
!default.mode2v3
*.perspectivev3
!default.perspectivev3
xcuserdata/
*.xccheckout
*.moved-aside
*.xcuserstate
*.xcscmblueprint
.AppSandboxPersistedFonts
CapsuleApp.xcresult
```

2. 保存が完了したら、ターミナルで以下のコマンドを実行し、クラウド（GitHub）へ安全に反映させます。

```bash
# 1. 変更のあったすべてのファイル（iOSAppフォルダ、.gitignore等）をステージングに追加
git add .

# 2. 明確でわかりやすいコミットメッセージを記録
git commit -m "feat: XcodeプロジェクトをiOSApp公式フォルダへ配置し構造を完全クリーン化"

# 3. GitHubの本番リポジトリ（クラウド）へ安全に送信！
git push origin main
```
