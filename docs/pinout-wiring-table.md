# 🔌 iRobapp-mini ピンアサイン・配線表

本プロジェクト（iRobapp-mini）の電気回路およびメインマイコン「XIAO ESP32-S3」におけるピン割り当ての全レイアウトです。実機のハンダ付けやファームウェア開発時のピン定義のマスターデータとして使用します。

## 1. 🟥 ⬛ 電源・給電ライン（バッテリー・メインスイッチまわり）
※システムの安定動作のため、すべてのデバイスのマイナス（GND）は最終的に1箇所にまとめて共通（コモングランド）に結束します。
※サーボモーター（SG90）は動いた瞬間に大きな電流を消費するため、マイコンのピンからではなく、バッテリー（3.7V〜4.2V）からダイレクトに電源を供給する「直結ルート」を採用しています。

| 送り元（ソース） | 受け手（ディスティネーション） | ワイヤー色 | 役割・備考 |
| :--- | :--- | :---: | :--- |
| **LiPoバッテリー (＋)** | ヒューズホルダーの一端 | 🟥 赤 | リチウムイオン電池の発火・過電流リスクからの保護（MF-R090） |
| **ヒューズホルダーの他端** | 電源スイッチの真ん中 | 🟥 赤 | 安全装置（ヒューズ）を通過した安全な電気 |
| **電源スイッチのON** | **【VCC分岐ハブ】**へ | 🟥 赤 | ロボット全体のメイン電源供給ON/OFFライン（SS-12D00G） |
| **【VCC分岐ハブ】** | XIAOマイコン の **`BAT+`** ピン | 🟥 赤 | バッテリー給電時のマイコン用メイン電源入力 |
| **【VCC分岐ハブ】** | 首振りサーボ（Pan）の **電源線** | 🟥 赤 | 左右駆動用（電池直結の3.7V〜4.2Vで駆動） |
| **【VCC分岐ハブ】** | 尻尾サーボ（Tail）の **電源線** | 🟥 赤 | 尻尾フリフリ駆動用（電池直結の3.7V〜4.2Vで駆動） |
| **LiPoバッテリー (－)** | **`GND共通1F`** / 全デバイスの **GND線** | ⬛ 黒 | **【GND共通ハブ】**にてすべてのマイナス線を1点に結束 |

## 2. 📺 丸型液晶（WAVESHARE 1.28inch LCD Module (19192)）SPI通信ライン
※液晶モジュール自体の電源（VCC/GND）は、内部の信号レベル（ロジック電圧）と同期させるため、XIAOマイコン側の `３V3` および `GND` ピンから給電します。

| XIAOマイコンのピン | 丸型液晶（19192）のピン | ワイヤー色 | 信号の種類（役割） |
| :--- | :--- | :---: | :--- |
| **`３V3` (3.3V)** | **`VCC`** | 🟪 紫 | 液晶ロジックおよびバックライト駆動用電源 (3.3V) |
| -- | **`GND`** | ⬛ 黒 | **【GND共通ハブ】**にてすべてのマイナス線を1点に結束 |
| **`D10` (GPIO09)** | **`DIN`** (MOSI) | 🟩 緑 | SPIメインデータ送信ライン（映像・ドットデータ） |
| **`D8` (GPIO7)** | **`CLK`** (SCLK) | 🟧 橙 | SPIクロック信号（マイコンと液晶の同期用シグナル） |
| **`D7` (GPI44)** | **`CS`** (Chip Select) | 🟨 黄 | 液晶デバイスを有効化/選択するための信号（Lowアクティブ） |
| **`D9` (GPIO8)** | **`DC`** (Data/Command) | 🟦 青 | 送信データが「画像データ」か「制御コマンド」かの識別信号 |
| **`D6` (GPIO43)** | **`RST`** (Reset) | 🟫 茶 | 液晶モジュールのハードウェアリセット信号 |
| **`D5` (GPIO06)** | **`BL`** (Backlight) | 🩶 灰 | 液晶バックライトの輝度・ON/OFF制御信号 |

## 🔊 5. 音響系：I2Sデジタルオーディオ（MAX98357 ➔ スピーカー）
※XIAOマイコンからデジタル信号（I2S規格）のまま音声データをアンプへ送り、MAX98357チップの内部でアナログへ変換＆大音量に増幅してスピーカーを鳴らします。

| XIAOマイコンのピン | アンプ（MAX98357）のピン | ワイヤー色 | 信号の種類（役割） |
| :--- | :--- | :---: | :--- |
| **`D2` (GPIO3)** | **`LRCLK`** (WS) | 🟪 紫 | 左右の音声チャンネル（L/R）を識別するワードセレクト信号 |
| **`D3` (GPIO4)** | **`BCLK`** (BCK) | 🩵 水色 | ビットクロック信号（データを読み込むタイミング用） |
| **`D4` (GPIO5)** | **`DIN`** (DATA) | 🟨 黄 | デジタル音声データ（オーディオ波形データそのもの） |
| -- | **`GND`** | ⬛ 黒 | **【GND共通ハブ】**にてすべてのマイナス線を1点に結束 |
| **`VUSB` (5V)** | **`2.5−5.5V`** | 🟥 赤 | 音声増幅アンプ駆動用メイン電源 |
| -- | アンプの **`+` / `L-`** ➔ **スピーカー端子** | 🛠️ 任意 | 増幅完了後のアナログ音声信号（直接スピーカーへ接続） |

## 🗺️ 6. 参考：Seeed Studio XIAO ESP32-S3 公式ピンマップ対比表
Arduinoコード（`main.ino`）の実装時や、生のGPIO番号を指定するライブラリ（LovyanGFX等）のピン定義の際に参照する、D番号と生のGPIO番号の公式対応表です。

| XIAOシルク（D番号） | 生のGPIO番号 | 本プロジェクトでの割り当て | 備考・相性（設計意図） |
| :---: | :---: | :--- | :--- |
| **`D0`** | **`GPIO 1`** | ⚙️ 首振りサーボ信号線（黄） | 起動時のノイズ影響が少ない安定ピン |
| **`D1`** | **`GPIO 2`** | ⚙️ 尻尾サーボ信号線（黄） | 起動時のノイズ影響が少ない安定ピン |
| **`D2`** | **`GPIO 3`** | 🔊 I2Sアンプ：`LRCLK`（紫） | クロップ干渉を防ぐI2S（GPIO3〜5）の3連番配置 |
| **`D3`** | **`GPIO 4`** | 🔊 I2Sアンプ：`BCLK`（水色） | クロップ干渉を防ぐI2S（GPIO3〜5）の3連番配置 |
| **`D4`** | **`GPIO 5`** | 🔊 I2Sアンプ：`DIN`（黄） | クロップ干渉を防ぐI2S（GPIO3〜5）の3連番配置 |
| **`D5`** | **`GPIO 6`** | 📺 丸型液晶：`BL`（灰） | 液晶バックライト輝度制御 |
| **`D6`** | **`GPIO 43`** | 📺 丸型液晶：`RST`（茶） | ⚠️**通信ワープピン**（起動時にパルスが走るため液晶制御に割当） |
| **`D7`** | **`GPIO 44`** | 📺 丸型液晶：`CS`（黄） | ⚠️**通信ワープピン**（起動時にパルスが走るため液晶制御に割当） |
| **`D8`** | **`GPIO 7`** | 📺 丸型液晶：`CLK`（橙） | SPIクロック同期ピン |
| **`D9`** | **`GPIO 8`** | 📺 丸型液晶：`DC`（青） | ディスプレイのデータ/コマンド識別 |
| **`D10`** | **`GPIO 9`** | 📺 丸型液晶：`DIN`（緑） | ⚡**高速ネイティブSPIピン**（LovyanGFXの描画を最大化） |

> 💡 **【設計メモ】D6/D7の特殊仕様について**
> 内部のGPIO番号が「43」「44」と突然ワープしているのは、ESP32-S3チップ本来のプログラム書き込み・通信用ピンをXIAO基板の外部ピンとして開放しているためです。
> 起動直後に一瞬パルス（ノイズ）が出やすい特性があるため、誤動作すると危険なサーボやアンプを避け、影響が出ない「液晶のリセット・CSピン」へ割り当てることで実機の100%安定動作を保証しています。
